# Demos

This folder contains **example applications** built with **SPA-JSPlus**.
Each demo highlights different aspects of the engine, such as routing behavior, lifecycle hooks, async builders, and differences between development and production modes.

> These demos are primarily aligned with **SPA v2.x (recommended: v2.0.3)**.

---

## Available Demos

### Core SPA Demo

A minimal demo that showcases the core concepts of SPA-JSPlus:

* History API vs Hash-based routing
* Reactor-based route definitions
* Lifecycle hooks (`onMeet`, `onArrive`, `onExit`, `onComeback`)
* Navigation stack behavior

Live demo:
[https://spajsplus.netlify.app/](https://spajsplus.netlify.app/)
