#### [2.0.3](https://github.com/dimaspandu/spa-jsplus/tree/main/spa/2.0.3)

> 18 January 2026

**Focus: SPA Engine Stabilization, Bundling Workflow, and Execution Modes**

- feat(spa): promote SPA v2.0.3 as the primary and recommended engine
- feat(spa): clear separation between **native ESM development mode** and **bundled production mode**
- feat(spa): introduce explicit runners:
  - `run.dev.js` → native browser ESM (no bundling, for learning & debugging)
  - `run.start.js` → bundled output served from `dist/`
  - `run.bundle.js` → single-file CDN build
- feat(bundler): improve dependency graph resolution for static and dynamic imports
- feat(bundler): generate single-file production bundle with global exposure (`window.Spa`)
- feat(spa): add intentional broken-route demo to illustrate CORS & dynamic import boundaries
- docs(spa): add full README for v2.0.3 explaining execution modes and architecture
- docs(root): refocus global README to highlight v2.0.3 as the main entry point

**Notes**
- Versions `< 2.0.x` are kept for historical and learning purposes.
- v2.0.3 is the first version designed to support:
  - native ESM (development)
  - bundled SPA (production)
  - CDN-distributed single-file usage
